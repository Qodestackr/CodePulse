Use tools like Portainer, Grafana, and Prometheus: As mentioned earlier, tools like Portainer, Grafana, and Prometheus provide web-based user interfaces and APIs for managing and monitoring Docker containers, and do not require running Docker commands directly from your Node.js application. These tools can be used to interact with Docker containers without needing sudo privileges in your Node.js application. However, you may need to configure appropriate permissions and access controls in these tools to ensure security.
